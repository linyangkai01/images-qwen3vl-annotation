# `open/` —— 开源资源子树

本目录是**开源资源**子树，与自有资源子树 `own/` **硬隔离**（约束 7 / 需求 4.1.B）。

## 隔离规则

| 子树   | 存放内容                                             | 是否入库 |
| ------ | ---------------------------------------------------- | -------- |
| `own/` | 真实素材派生数据、私有端点配置、场景专用提示词       | 配置/提示词入库，素材与产物不入库 |
| `open/`| 开源权重来源、许可记录、开源工具说明                 | 记录入库，**权重本体不入库**（`open/weights/` 已 gitignore） |

**只进不出**：可联网下载开源资源，但**不得上传或携带任何私有素材**。

## 目录结构

```
open/
├── README.md        # 本文件：开源资源清单与隔离说明
├── licenses.md      # 许可记录（Ultralytics AGPL-3.0 等）
└── weights/         # 下载的开源权重（不入库，见 .gitignore）
```

## 开源资源清单

| 资源 | 用途 | 获取方式 | 许可 |
| ---- | ---- | -------- | ---- |
| Ultralytics YOLO（`yolo11n.pt` 等） | 通用零样本初检 / 冷启动训练起点 | `pip install ultralytics`（仅 lab-server，`optional-dependencies.production`） | AGPL-3.0（见 `licenses.md`） |
| 母项目 `traffic_cv_closed_loop` | 两段式标注骨架（`import` 复用） | 本仓库内，母项目一行不改 | 见仓库根 `LICENSE` |

> SAM 类 / 开放词汇检测模型**尚未引入**；引入前必须先确认许可并在此登记（约束 7 / 需求 4.1.A.2）。

## 权重存放

下载的开源权重统一放 `open/weights/`，该目录已被 `.gitignore` 排除。
自有训练产出的权重属于**交付物**，按版本化目录管理（`workspace/runs/<版本>/`），
**不得混入 `open/`**。
