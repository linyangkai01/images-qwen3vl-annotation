## 建议的删除方式

在项目根目录执行以下脚本命令（**先干跑确认，再实际删除**）：

```
Get-ChildItem -File _* | Where-Object { $_.Extension -in ".log",".py",".txt",".json",".png" } | Remove-Item -WhatIf
```

确认列表无误后，去掉 `-WhatIf` 实际执行。

> 说明：主理人尝试批量删除时被沙箱安全机制拦截（单轮删除量超阈值），故未代为执行。
