## 〇、先说三件最重要的事

**第一件（最紧急）：报告里「197 条隐患 / D-5-3 占 43%」这个数字，可能本身就是错的。**

197 条隐患来自 323 帧，平均每帧 0.61 条。抽帧是**连续**的，同一个吊运事件会跨越多个帧被**重复输出**。D-5-3 的 85 条，很可能只是 **8~15 个真实事件 × 每事件 6~10 帧**的重复计数。**不按事件去重就谈占比，这个数字没有意义。**

这件事成本几乎为零（写个聚类合并脚本），但可能直接改写报告结论。**建议第一个做。**

**第二件：判定「人在吊物下方」不需要 3D 重建，射影几何就够，而且能做得比 3D 方案好。**

- 纯 2D 框判定：Singh & Seif 2026 实测 **P=0.523 / R=0.852**【实】
- 做**地面投影**（把吊物投影到地面再判）：Chian et al. 2022（Safety Science）实测 **P=0.86 / R=0.83**【实】

差距 0.52 → 0.86。而地面投影**不需要深度、不需要吊索方向** —— 只需要重力方向和地面平面（见第四节）。这是本次调研最有价值的发现。

**第三件：换 Instruct 权重不只是「快 10 倍」，可能还「更准」。**

Qwen3-VL 技术报告（arXiv:2511.21631）【实】：32B 上 RealWorldQA **Instruct 79.0 vs Thinking 79.4**，OCR/文档类任务 **Instruct 略优**，官方原文写 "Instruct even outperforms the Thinking variant"。

我的任务是**感知类**（画框 + 识别隐患），不是深推理。**换 Instruct 很可能是又快又好，不是用质量换速度。**

## 二、核心诊断：报告里 8 个问题的真实性质

报告把下面这些混为一谈了，但它们的根因完全不同，治法也不同：

**类型 B · 数字本身可能错了（最高优先级）**

**类型 C · 判据与接线问题（v1 已识别，本版升级方案）**

## 三、第一件事：事件级去重（0.5 天，但可能改写结论）

### 为什么必须先做

197 条 / 323 帧 = 0.61 条每帧。D-5-3 有 85 条 = 26% 的帧都判"人在吊物下"。

对一段吊装作业视频，如果工人一直在吊物附近作业，这个比例**可能是真的**；但也**可能只是 8 个事件 × 10 帧**的重复。**不区分这两种情况，后面所有关于"43%"的讨论都是空中楼阁。**

### 怎么做

1. 按 `source_id` 分组，按 `frame_index` 排序
2. 同一 `hazard_id` 在**时间上连续**（间隔 ≤ N 帧，建议 N=3~5，即 ≤ 23 秒）的条次**合并为 1 个事件**
3. 事件记录：`{hazard_id, source_id, start_frame, end_frame, frame_count, 代表帧}`
4. **重算占比**：`事件级 D-5-3 占比 = D-5-3 事件数 / 全部事件数`

### 判定阈值

- 若事件级 D-5-3 占比**仍 ≥ 35%** → 占比结论成立，继续查 VLM 偏置
- 若**降到 20% 以下** → 说明原报告严重夸大，需重出报告
- 同时报告两个数字（帧级 / 事件级），**不要只报一个**

### 顺带的收益

去重后真实事件数可能只有 **20~40 个**。这意味着：
- 人工验证成本从"85 条"降到"8~15 个事件"
- 验证方案（第七节）的样本量门槛容易达到

## 四、几何判定的正确做法（射影解，不用 3D）

### 4.1 为什么纯 2D 框不够，而地面投影够用

Singh & Seif 2026【实】列出的核心失败模式原文：

> "monocular 2D overlap triggers a false hazard despite true depth separation"

即：**人在吊物后方 5 米，但 2D 投影重叠 → 误报**。这是 P=0.523 的主因。

而 Chian et al. 2022（Safety Science）【实】做的是：检测吊物关键点 → **把吊物面积投影到楼面** → 检测跟踪工人 → 判定。**P=0.86 / R=0.83**。

**差别就在"投影到地面"这一步。** 而这一步不需要深度：

### 4.2 射影解（关键：不需要吊物的深度，也不需要吊索方向）

判定「人在吊物下方」只需要三件事：

1. **重力方向**（垂直消失点）—— 单帧即可估计（GeoCalib【实】，pitch 中位误差 0.87~1.94°，100ms/帧）
2. **地面平面** —— 静态相机下只剩 1 个未知数（相机高 h），可用**人高先验 1.7m + 框像素高** RANSAC 反解
3. 然后：
   - 吊物地面投影点 = 过吊物中心的**铅垂射线** ∩ 地面平面
   - 人脚点 = 过人框底边的射线 ∩ 地面
   - 比较两点的**地面距离**是否落在「吊物足迹半径 + 安全余量」内

**【推】这是射影几何常识，在射影层面严格成立**，唯一软约束是尺度（米制需要锚定）。

### 4.3 误差界（可算，不是拍脑袋）

射线-地面交点距离对俯仰角误差的敏感度：**Δd ≈ (d²/h)·Δα**【推，针孔模型推导】

取 h=3m、d=15m：

- GeoCalib 单帧 1° pitch 误差 → **Δd ≈ 1.3 m**
- 415 帧时间平均 + 人高约束联合平差后，Δα 可望 0.2~0.5° → **0.3~0.7 m**【推】
- **相机越高越好**：h=15m 时系数降到 26.7 m/rad，1° 仅 0.47 m
- 横向误差 Δx = (d/f)·Δu：d=15m、f≈1000px、框 5px 误差 → **7.5 cm**，几乎免费
- 尺度锚定误差：人高 1.7±0.1m ≈ 6%，15m 处 ≈ 0.8m【推】
- **利好**：判定是**差分**比较（人 vs 吊物，深度相近），系统性 pitch 误差**大部分抵消**

**结论：在 15m 距离上，射影解的误差约 ±0.5~1.0m，容差够用**（OSHA 的 fall zone 本身就是"可合理预见"的模糊区域）。

### 4.4 可直接采用的公式（Singh & Seif 2026【实】）

作为 V1 的几何层，直接抄他们的：

- **工人脚点** = 框底中心（不是框中心！）
- **净空比** `r_clr = (y_foot_worker − y_bottom_load) / h_worker`，阈值 **0.12**（用人像素高归一化，抗视角变化）
- **梯形坠落区**：半宽从载荷底部 `w/2 + 30px` 线性扩展到地面 `w/2 + δ_lat`；`δ_lat = v_eff · t_fall`，`t_fall = √(2h/g)`，漂移速度下限 0.4 m/s
- **垂直门控**：脚点须在载荷底边下方 **≥40px**（抑制"载荷上方远处的人"误报）
- **时序**：1 秒滑窗（15 帧）内 ≥10 帧命中才判 Unsafe
- **像素-米代理**：`ρ = 中位工人像素高 / 1.75m`

⚠️ **降权说明**：他们的评测集 SynthSite 是 **AI 生成的合成视频**（55 段），且是 CVPR **workshop** 论文。真实场景的 P 大概率还要更低。

### 4.5 我不知道的一个前提：相机是静止还是运动

**这决定整条路怎么走，必须先花 0.5 人日诊断**：抽 20~30 帧跑 VGGT，看相对平移 ‖t‖。

- **相机静止**（工地固定摄像头，最常见）→ 多视角重建**原理上给不出深度**（基线≈0），这条路废掉；**但这是好消息**：地面平面在世界系固定，**只需标定一次**，且可用人高先验反解
- **相机运动**（手持 / 随车 / PTZ）→ 多视角重建有价值，但吊物是大面积运动物体，正是 VGGT 明确会失败的场景（论文 Limitations 原文："fails in scenarios involving substantial non-rigid deformation"）

**我的判断【推】**：大概率是静止摄像头。如果是，走**单视图度量 + 铅垂投影**路线，不做重建。

## 五、明确「不做什么」（严谨性体现在知道边界）

**不做 1 · 单目深度估计（Depth Anything V2 等）**

判为**净负担**。理由：
- 要分辨的信号（人-物深度差 2~6m @ 10~25m）vs 深度噪声（零样本室外 δ1≈85~88%，域外【推】退化到 0.75~0.85，即 20%+ 像素相对误差 >25%）
- **信噪比约 1:1** —— 深度噪声和 2D 投影歧义**同量级**，加了也白加
- 15m 处真实误差【推】±1.5~3m，不可接受
- 更致命：**没有 3D 真值，无法验证它有没有帮上忙**
- 唯一例外：把深度当作**三级不确定性输出的一个特征**（|Δ|<0.10 疑似 / 0.10~0.25 危险 / ≥0.25 且时序持续 → 确定），有小正收益

**不做 2 · 多视角 3D 重建（VGGT / DUSt3R / MASt3R-SLAM）**

判为**不划算**（10~20+ 人日）。理由：
- 它**同样需要人高锚定尺度**，不能消除核心误差源
- VGGT 明确会败于大面积运动物体（吊物正是）
- **没有 3D 真值**，只能靠人工标注几十帧做弱校验
- **而且：**这些模型输出是**尺度歧义**的（VGGT 用"点云到原点平均距离"规范化），得到的不是米制

**不做 3 · 改损失函数（Seesaw / EQLv2 / BalancedGroupSoftmax）**

- 【实】**无任何适配 Ultralytics YOLO 的第三方实现**，需自己在 `v8DetectionLoss` 里替换 BCE（约 20 行）
- BalancedGroupSoftmax 仓库 2022-06 停更；Seesaw/LDAM 移植版检索无命中
- 【推】对 292 条样本，收益 < 数据侧清洗。**收益/成本比不划算**

**不做 4 · Ultralytics 内置 copy_paste**

【实】官方要求 **polygon 标签，只对 segment/OBB 生效，纯 bbox 的 detect 任务不生效**；IoA 阈值硬编码 0.3 不可调；`close_mosaic` 触发时会连带关闭。**改用 `cutmix`（基于框工作）或自己写 bbox 版。**

**不做 5 · 追求「物理正确的米制 3D 判定」**

【推】单目 + 无标定 + 无深度真值 ⇒ 严格米制 3D **不可辨识**（仅到相似变换）。但**存在"物理正确"的射影解**：铅垂投影在射影层面严格成立，唯一软约束是尺度。

**定位为「风险提示级输出 + 不确定度分级」是诚实且够用的；声称厘米级 3D 判定属于过度承诺。**

**不做 6 · 用主动学习挑验证集来报总体准确率**

【实】主动采样使选中概率 q_i 与 y 相关，子集均值是**有偏估计**。要无偏估计只能靠**概率抽样**（简单随机/分层 + 事后加权）。主动学习优化的是"模型改进"，我要的是"总体参数无偏估计"，**目标函数冲突**。

## 七、验证方案（统计严谨，这是最容易被糊弄过去的一环）

### 7.1 核心困境

- 检测框是 VLM 伪标签，**无人工金标准**
- 我写的几何规则，**无 ground truth 验证**
- Singh & Seif【实】实测：**人类标注者之间 Cohen's κ 仅 0.308**

### 7.2 κ=0.308 意味着什么（别误读）

Landis & Koch (1977)【实】：<.20 slight / **.21–.40 fair** / .41–.60 moderate。κ=0.308 = **fair**。
Krippendorff 门槛【实】：**α≥0.80 才可靠**，<0.67 不可用于三角验证。

**κ 低不代表我的规则差**【推】：对称误差模型下（prevalence=0.5）κ=(1−2ε)² ⇒ **ε≈22%**，即**完美规则对单人标注的一致率上限仅 ≈78%**。我测到 0.7 未必差。反解真准确率：`a_true = (a_obs − ε) / (1 − 2ε)`。

**结论：单人标注不足以当金标准，必须 ≥3 人 + 多数投票/仲裁**（3 人多数投票把 ε 从 22% 降到 ≈12.6%【推】）。

### 7.3 无金标准时的统计解法

**Dawid–Skene EM / 潜类别模型（LCM）**【实】：用多名标注者的交叉标注**同时估计隐含真值与每个标注者的敏感度/特异度**，无需任何真值。系统综述证实 LCM 用于无参考标准的诊断准确性评估。

**Rogan–Gladen 校正**【实】：校正患病率点估计 `p_true = (p_obs + Sp − 1) / (Se + Sp − 1)` —— 这是回答"43% 是否虚高"的**统计学标准工具**。

### 7.4 样本量（我算的，不是拍的）

CI 宽度法 `n = z²·p(1−p)/d²`，p=0.7：

- 半宽 **±0.05 → n=323**
- 半宽 **±0.10 → n=81**
- 最保守 p=0.5：385 / 97

**关键修正 —— 聚类相关【算】**：323 帧来自 31 个视频（m̄≈10.4），若 ICC ρ=0.3，设计效应 `DEFF = 1+(m̄−1)ρ ≈ 3.8`，**有效样本 ≈85，半宽退化到 ±0.097**。

→ **必须按视频聚类抽样 + 聚类 bootstrap**，不能当 323 个独立样本。

**建议方案**：31 个视频 × 每视频约 5 帧 ≈ **155 帧**，3 人独立标注 + 第三人仲裁，配聚类 bootstrap 报 CI（预期半宽 ≈±0.07）。

### 7.5 误差来源拆分（框错 vs 规则错）

**2×2 因子消融**：人工在验证子集上标**两个量** —— (i) 语义金标（人是否在吊物下）、(ii) 框是否需要修正。四条件：{VLM框, 人工框} × {原规则, 无规则基线}。

- 纯规则误差 = E(人工框)
- 检测引入部分 = E(VLM框) − E(人工框)
- 交互项用 Shapley 归因

两组结果在**同一批帧**上是配对的 → 用 **McNemar 检验**（非独立 z 检验）。

### 7.6 阈值敏感性分析

1. **OAT 网格扫描** τ∈[0,1] step 0.05，画 accuracy/recall–τ 曲线，报告**平台区宽度**与**翻转率**（τ±0.1 时判定改变的帧占比）
2. 算每个样本的**决策余量** |overlap − τ|，余量小的帧即脆弱点
3. **框扰动蒙特卡洛**：对框角点加 σ=0.02w/0.05w 高斯抖动，重算规则，统计翻转率

### 7.7 人工验证实验设计

- **盲法**：标注者不得看到规则输出与视频来源（防锚定）
- **随机化**帧序，混入 5~10% 重复帧测**自身一致性**
- 加 golden items 监控标注漂移
- **Pilot 30~50 帧 → 算 κ/α → 修订指南 → 再 pilot**（迭代式校准）
- **判定题要重新设计**：隐患含时序维度，单帧问"是否危险"是**病态问题**；要么给 ±N 帧上下文，要么明确定义为帧级几何关系，并**单独设"不确定/无法判断"第三类**
