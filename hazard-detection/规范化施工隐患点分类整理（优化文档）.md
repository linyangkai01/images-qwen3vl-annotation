# 规范化施工场景隐患点分类整理

## 一、吊装作业隐患点

### 1. 吊索具缺陷与使用不当

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| D-1-1 | 绳索交叉缠绕 | 交叉、缠绕两者均不行 |
| D-1-2 | 绳索缠绕 |  |
| D-1-3 | 吊链/吊带与硬质表面接触，无衬垫、保护套等防割措施 | 存在物体打击风险 |
| D-1-4 | 吊带无明显割口损伤（使用前未检查） | — |
| D-1-5 | 吊钩与被吊物品连接不牢固 | — |
| D-1-6 | 吊具与索具未标识可承重重量 | — |
| D-1-7 | 吊装无牵引绳 | 可能存在视频角度问题，可能实际有 |

### 2. 吊架/托架使用不规范

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| D-2-1 | 吊架不平衡 | — |
| D-2-2 | 吊架下的吊链斜拉 | 难以识别 |
| D-2-3 | 使用卡板吊重物（禁止） | 有规范 |
| D-2-4 | 托架捆绑不牢靠 | — |
| D-2-5 | 违规使用托盘作为吊具或承重平台 | — |

### 3. 被吊物品不安全状态

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| D-3-1 | 散件未用料斗吊运/未可靠捆绑固定 | 禁止，有规范，**必须用料斗或其他防脱落措施** |
| D-3-2 | 小构件吊装未采取防脱落措施 | 禁止 |
| D-3-3 | 大件物品未使用平衡梁 | 要求使用平衡梁 |
| D-3-4 | 重物直接压在吊装带上 | 禁止                                         |
| D-3-5 | 吊物悬停在通道上方 | 禁止 |
| D-3-6 | 吊物悬停在空中 | 禁止 |
| D-3-7 | 相邻龙门吊同时运行，重物长时间悬停 | — |

### 4. 作业环境与照明

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| D-4-1 | 吊装作业照明不足 | 要求充足照明 |
| D-4-2 | 吊装作业区域违规停放电瓶车 | — |
| D-4-3 | 是否存在歪拉斜吊行为 | — |

### 5. 人员不安全行为

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| D-5-1 | 人员未佩戴安全帽 | 要求全员佩戴 |
| D-5-2 | 人员未穿着反光背心或安全警示服 | 要求全员穿戴 |
| D-5-3 | 人员站在吊物下方/上方 | 物体打击风险 |
| D-5-4 | 吊物未放稳人员即上车操作 | — |
| D-5-5 | 人员离开现场未收回吊链 | — |

## 二、高处作业隐患点

> 高处作业包括：攀登与悬空作业、洞口与临边作业、坡度大于45°的斜坡上作业

### 1. 防护设施缺失

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| G-1-1 | 平台无防护栏/脚手架护栏缺失 | 2m以上需设防护栏 |
| G-1-2 | 脚手架、脚手板连接处或转角处缺失 | 人员跌落风险 |
| G-1-3 | 无防护措施的超高马凳（缺护栏） | — |
| G-1-4 | 屋顶/地面/楼梯/坡道/工作台等＞2m位置未设防护栏 | — |
| G-1-5 | 防护栏杆缺失（图片难辨认） | — |

### 2. 个人防护用品（PPE）

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| G-2-1 | 人员未佩戴安全帽 | 要求全员佩戴 |
| G-2-2 | 人员未系安全带 | 高空作业必须系 |
| G-2-3 | 未系安全绳高空作业 | 高空作业必须系 |
| G-2-4 | 未使用防滑鞋 |  |

### 3. 安全带/安全绳使用不规范

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| G-3-1 | 安全带未挂在牢固结构件上 | 应高挂低用 |
| G-3-2 | 安全带/安全绳打结使用 | 禁止 |
| G-3-3 | 不具备挂条件时未增设生命绳/速差防坠器/安全绳自锁器 | — |

### 4. 梯具使用不规范

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| G-4-1 | A字梯横跨作业 | 禁止 |
| G-4-2 | 梯具未放置在平实地面 | — |
| G-4-3 | 踢脚之间无固定扣件 | — |
| G-4-4 | 梯脚无防滑措施 | — |
| G-4-5 | 禁止单人作业（下方无人稳固梯具） | — |
| G-4-6 | 踩于最高梯面作业 | 禁止 |
| G-4-7 | 坐/站于A字梯上端两阶和顶端 | 禁止 |
| G-4-8 | 人字梯上部夹角不在35°~45°范围 | — |
| G-4-9 | 直梯垫高使用 | 禁止 |
| G-4-10 | 直梯工作角度不在70°~80°范围 | — |
| G-4-11 | 使用便携式梯子下方无人扶持 | — |

### 5. 移动脚手架使用不规范

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| G-5-1 | 作业中支架受水平冲击/撞击 | 应避免 |
| G-5-2 | 移动到位后未锁定轮子/未加斜支腿 | — |
| G-5-3 | 移动脚手架载人移动 | 禁止 |
| G-5-4 | 超两层脚手架底部带轮 | 禁止 |

### 6. 作业行为与环境

| 隐患编号 | 隐患点 | 备注 |
|---------|--------|------|
| G-6-1 | 人员进行横跨作业 | 禁止 |
| G-6-2 | 高处坠落区域内从事交叉作业（未搭防护顶棚） | 禁止 |
| G-6-3 | 登高作业照明不足 | 要求充足照明 |

## 行车六严禁  

1.严禁反车制动限位起升机构 

2.严禁撞击限位硬停车 

3.严禁未稳钩多档位同步操作 

4.严禁吊物越人头，吊运离地≤0.5m 

5.严禁同柱距停放两台行车

6.严禁同轨吊车互相碰撞
